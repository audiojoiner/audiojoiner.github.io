> **Audio Joiner** is a radically minimal, ultra-fast, and 100% client-side web DAW (Digital Audio Workstation) utility designed to merge, trim, reorder, and crossfade multiple audio tracks directly in your browser.

🌐 **Live URL**: [https://audiojoiner.github.io/](https://audiojoiner.github.io/)

---

## 🌟 Key Features

* 🔒 **100% Client-Side & Private**: Powered entirely by WebAssembly (`@ffmpeg/ffmpeg`) and the Web Audio API. Your audio files never leave your computer or phone — zero server uploads, zero storage, zero tracking.
* 🎚️ **Visual Waveform Editing**: High-definition interactive waveforms generated by `WaveSurfer.js` for each audio track with dynamic light/dark theme adaptation.
* ✂️ **Dual Draggable Trim Handles**: Easily trim track intros and outros with interactive `START` and `END` draggable vertical handles directly on the waveform, with real-time timecode tooltips and sub-second precision inputs.
* ✨ **DJ-Style Crossfade Transitions**: Seamlessly blend songs together with automatic volume crossfades to eliminate abrupt transitions and awkward silence.
* 🔄 **Multi-Format Transcoding**: Merge disparate audio formats together (MP3, WAV, M4A, AAC, FLAC, OGG, Opus, WebM) and export into your choice of **MP3, WAV, M4A, OGG, or FLAC** with custom bitrates (up to 320 kbps).
* ☀️/🌙 **Light & Dark Theme Switcher**: Instant theme toggle with zero-flicker head script initialization, localStorage persistence, and live canvas re-coloring.
* 📱 **Universal Cross-Device Responsiveness**: Fully responsive layout tailored for mobile phones, tablets, laptops, and ultrawide desktop monitors with touch drag support.
* 🌍 **Global 6-Language Subpath Routing**: Full internationalization for **English (`en`)**, **Spanish (`es`)**, **Portuguese (`pt`)**, **German (`de`)**, **French (`fr`)**, and **Japanese (`ja`)** with 7 bidirectional `hreflang` alternate tags and crawlable language switchers.
* 🚀 **100% SEO-Optimized**: Comprehensive JSON-LD structured data (`WebApplication`, `WebSite`, `Organization`, `HowTo`, `FAQPage`, `BreadcrumbList`), Open Graph metadata (1200x630 Cloudinary banner), and XML sitemaps with `xhtml:link` annotations.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18.14.1 or higher) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/audiojoiner/audiojoiner.github.io.git
   cd audiojoiner.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:4321](http://localhost:4321) in your browser to view the application.

4. **Build for production:**
   ```bash
   npm run build
   ```
   This generates the production-ready static site inside the `dist/` directory.

5. **Preview the production build locally:**
   ```bash
   npm run preview
   ```

## ⚙️ How It Works (WebAssembly Pipeline)

```
[User Audio Files] 
       │
       ▼
[Web Audio API (Metadata & Waveform Preview)]
       │
       ▼
[Track Reordering, Start/End Trim, & Crossfade Setup]
       │
       ▼
[Single-Threaded FFmpeg.wasm Engine (@ffmpeg/core)]
       │
       ├─ Step 1: Write input files to virtual WASM FS
       ├─ Step 2: Build FFmpeg filtergraph (atrim, acrossfade, asetpts)
       ├─ Step 3: Transcode to target format (MP3, WAV, M4A, OGG, FLAC)
       └─ Step 4: Read virtual output file and package as Blob URL
       │
       ▼
[Instant In-Browser Download (Zero Server Uploads)]
```
